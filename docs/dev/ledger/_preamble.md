# Roadmap

Decisions about `model-sync`: what was asked, what was ruled, and why it is the shape it is. Not an
issue tracker: an entry ruled against and never built is as useful here as one that shipped,
because it stops the question being reopened.

The tickets under `docs/dev/ledger/` are the record. `roadmap build` prints them as one page, opened
by this text; no copy of that page is kept.
